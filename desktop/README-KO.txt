Aurelia Core — 오프라인 데스크톱 버전

[Windows]
1. AureliaCore-win-x64.zip 압축을 풉니다. (압축을 푼 폴더 안의 파일들은 함께 있어야 합니다)
2. 폴더 안의 AureliaCore.exe 를 실행합니다.
   - 처음 실행할 때 "Windows의 PC 보호" 창이 뜨면 [추가 정보] → [실행]을 누르세요.
     (서명되지 않은 개인 제작 앱이라 표시되는 안내입니다)
3. 인터넷 연결 없이 플레이할 수 있습니다. 진행은 이 PC에 자동 저장됩니다.

[Linux]
1. AureliaCore-linux-x64.zip 압축을 풉니다.
2. 터미널에서 ./AureliaCore 를 실행합니다.

[다른 기기로 진행 옮기기]
게임 안 설정 → 저장 데이터 → 코드 복사/파일 저장 후, 다른 기기에서 불러오기 하면 됩니다.
