# Prompt sheet — worldline select chrome

Paste-ready. Use with `00-shared-base.md` rules. Palette roles are **PROVISIONAL — not locked brand**.

## Subject

Sci-fi dark UI chrome for choosing a rebirth worldline: four selectable cards in a clean 2×2 arrangement, with restrained focus/hover treatment and a clear confirm area. This is interface framing, not a poster and not a logo sheet.

## Canvas / layout

- **Primary:** 1920×1080 landscape
- Four equal cards: **Directive Pulse**, **AURELIA Grid**, **Resonance Protocol**, **Volatile Core**
- Keep generous outer margins and a clear center/edge hierarchy for runtime HUD placement
- Each card gets a small abstract motif cue only: chevrons/pulse bars, square grid, concentric arcs, cracked core
- Use exact worldline names as simple UI labels if the tool renders text reliably; otherwise leave clean label zones for runtime text

## Palette roles (PROVISIONAL)

- Shared frame: `role_void` ~#05070D, `role_ui_ink` ~#0B0F1A, `role_highlight_white` ~#E8F4FF
- Directive Pulse card accent: cool cyan / electric blue
- AURELIA Grid card accent: warm gold / amber
- Resonance Protocol card accent: magenta / violet
- Volatile Core card accent: hot orange / crimson

Use one restrained accent per card. These are provisional color roles, not locked hex values. Avoid a rainbow blend across the whole frame.

## Art direction

- Dark translucent plates, thin technical borders, subtle corner brackets, small status ticks, clean alignment
- One card may have a brighter selection outline, but keep all four cards equally legible
- Abstract motifs must remain subordinate to the card chrome
- No brand marks, emblems, corporate logos, seals, mascots, characters, or fake product logos
- No dense readable paragraphs, stats, or invented button copy
- Flat orthographic game UI, sharp edges, soft controlled bloom, high contrast, mobile-aware spacing
