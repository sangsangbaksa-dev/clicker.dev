# clicker-rebirth-motion

Art direction pack for **hsms-md** rebirth / worldline transition motion. No code. No generated images.

## Contents

1. `rebirth-motion-spec.md` — beat timeline, VFX layers, per-worldline variants, web implementation notes
2. `prompt-sheets/` — paste-ready image prompts (shared base + collapse + 4 stamps + rebuild)
3. `handoff-for-cursor.md` — implementation order and acceptance for Cursor agent clicker.md.Waldo
4. `prompt-sheets/07–09` — particles/overlay plates, worldline-select chrome, and reduced-motion stills

## How Cursor should use this

1. Read `handoff-for-cursor.md` first.
2. Implement motion from `rebirth-motion-spec.md` (timeline + layers). Do not invent assets beyond this pack.
3. Paste prompts from `prompt-sheets/*.md` into the user's image tool; filename conventions are in each sheet.
4. Colors marked **PROVISIONAL** — replace when a style guide locks hex values. Do not treat provisional hex as final brand.
